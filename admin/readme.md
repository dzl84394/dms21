## 一、基础必选（如果还没写，优先补上）

1. **架构资产台账**
   - 应用拓扑、依赖图谱、服务调用链路、组件清单、存储资源归属
   - 架构元数据：应用负责人、技术栈、部署环境、SLA 等级、业务域归属
2. **架构规范中心**
   - 编码规范、接口规范、数据库设计规范、中间件使用规范、安全架构规范
   - 规范版本管理 + 变更记录，支持规范引用、在线查看
3. **架构评审管理**
   - 评审工单流程：提交方案→预审→专家评审→问题闭环→归档
   - 评审模板、问题库、整改跟踪、评审报告存档

## 二、进阶治理项（推荐补充，贴合微服务治理场景）

4. **技术栈管控**
   - 允许 / 禁用技术白黑名单，组件版本管控，识别应用中违规依赖
   - 技术栈统计大盘：各语言 / 框架使用占比，老旧框架清单
5. **技术债务管理**
   - 债务采集、分级标签（高危 / 中 / 低）、责任人、排期、跟踪闭环
   - 债务趋势报表，关联架构评审、代码扫描缺陷
6. **API 架构治理**
   - API 资产、API 契约管理（OpenAPI）、接口依赖、接口变更审批、版本管理
   - 接口兼容性校验，避免下游服务被上游改动击穿
7. **数据库架构治理**
   - 表结构变更评审、SQL 规范、慢 SQL 资产、数据库对象台账、分库分表拓扑
8. **架构变更管控**
   - 架构级变更工单：服务拆分、存储迁移、跨域依赖调整、中间件替换
   - 变更影响分析：评估上下游依赖，风险评估，回滚方案登记

## 三、可视化 & 观测类补充

9. **架构可视化**
   - 业务域架构图、系统上下文图、部署架构图，支持在线绘图与版本归档
   - 动态依赖图谱（和可观测链路打通，自动绘制，不是纯手工画图）
10. **架构健康度大盘**
指标示例：规范合规率、技术债务数量、高危依赖数量、架构评审通过率、违规应用数

## 四、权限与审计

11. **架构资产权限 & 操作审计**
   - 资产读写权限、域负责人权限隔离
   - 所有架构变更、评审、资产修改留审计日志

## 五、可选延伸（看平台定位，轻量平台可以不做）

- 容量架构评估：资源水位、扩容规划、压测报告归档

## 当前实现进展（2026-10-18）

规划已落成一组 Spring Boot 4 微服务（JDK 21，全部注册 Eureka；SSO 统一登录：DMS_TOKEN Cookie，HMAC-SHA256 签名，12 小时有效，未登录访问 /admin/* 统一 302 到 serviceAdmin 登录页）：

| 服务 | 端口 | Eureka 注册名 | 职责 |
| ---- | ---- | ---- | ---- |
| eureka | 8761 | — | 注册中心 |
| serviceA / serviceB | 8081 / 8082 | service-a / service-b | 业务演示服务（springdoc Swagger 入参演示） |
| serviceAdmin | 8083 | service-admin | Eureka 只读大盘 + 跨服务跳转枢纽。业务领域/子系统/中间件维护已全部下线收敛至 cmdbAdmin，旧路由（/admin/services、/admin/middleware 等）302 过去 |
| userAdmin | 8084 | user-admin | 用户/部门/权限（RBAC 按子系统隔离），SSO 令牌签发方，/api/auth 免登录校验 |
| archadmin | 8085 | arch-admin | 架构图（Mermaid，按子系统 × 图类型）+ 服务依赖关系（节点清单取 cmdbAdmin /api/nodes） |
| projectAdmin | 8086 | project-admin | 项目立项 / 版本 / 需求 / Bug / 故障 / 工时管理 |
| devopsAdmin | 8087 | devops-admin | 研发交付 / 质量测试 / 日志链路（导航占位） |
| baseAdmin | 8088 | base-admin | 注册/配置/调度/网关/MQ 等（导航占位） |
| commonAdmin | 8089 | common-admin | 统一存储 / 文档 / 签约 / 消息推送（导航占位） |
| apiAdmin | 8090 | api-admin | Swagger 文档导入（namespace/微服务/版本快照归档）+ API 清单解析 |
| cmdbAdmin | 8091 | cmdb-admin | CMDB 主数据：公司 → 业务领域 → 子系统 → 业务模块，环境 / 资源 / 版本；微服务与中间件登记落 t_service_group（Eureka 注册表自动同步，metadata 子系统编码匹配不到则置空待人工挂载）；免登录接口 /api/subsystems、/api/bizdomains、/api/nodes |

分工约定：主数据（公司/领域/子系统/微服务/中间件）统一在 cmdbAdmin 维护；serviceAdmin 只读注册中心、不再落库；各子系统侧边栏跨服务入口统一沉底，按端口排序。
